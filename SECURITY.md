# Seguridad y privacidad · El Formador Junior

El Formador Junior prioriza recursos pedagógicos digitales ligeros, reutilizables y respetuosos con la privacidad.

## Principios de seguridad

Los recursos del proyecto deben evitar, siempre que sea posible:

- Recoger datos personales.
- Solicitar nombres completos, DNI, teléfono o correo electrónico.
- Crear cuentas de usuario.
- Usar login innecesario.
- Enviar respuestas del alumnado a servidores externos.
- Incorporar analítica invasiva.
- Guardar información sensible.
- Publicar claves, tokens, credenciales o archivos de configuración privados.

## Datos personales

Como regla general, los recursos deben funcionar sin pedir datos personales.

Cuando una actividad necesite ejemplos personales, se recomienda usar datos ficticios o simulados.

## Recursos con código

Antes de publicar o actualizar un recurso con código, revisar:

- Que no haya claves API ni secretos en el repositorio.
- Que no se envíen datos a servicios externos sin explicación clara.
- Que el recurso pueda usarse sin registro.
- Que el README indique si recoge o no recoge datos.
- Que el recurso funcione en móvil y escritorio cuando proceda.

## Uso de IA

No deben introducirse datos personales sensibles del alumnado, docentes o terceros en herramientas externas de IA.

Si un recurso usa IA o servicios externos, debe documentar claramente:

- Qué datos se introducen.
- Qué servicio se utiliza.
- Para qué finalidad.
- Qué alternativa existe si no se quiere usar ese servicio.

## Reportar problemas

Si detectas un problema de seguridad, privacidad o exposición accidental de datos, no lo publiques como issue abierto.

Contacta directamente con el responsable del proyecto por un canal privado o profesional.
