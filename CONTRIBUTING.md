# Guía de contribución · El Formador Junior

El Formador Junior es un proyecto personal de portfolio técnico-docente orientado a crear recursos pedagógicos digitales reutilizables para formación de adultos.

## Criterios generales

Toda aportación debe respetar estos principios:

- Claridad pedagógica.
- Utilidad práctica.
- Lenguaje adulto, sencillo y no infantilizado.
- Tecnología ligera siempre que sea posible.
- Privacidad desde el diseño.
- Accesibilidad práctica.
- Documentación mínima.
- Revisión humana cuando se use IA.

## Antes de proponer cambios

Antes de modificar un recurso, revisa:

- Qué objetivo de aprendizaje tiene.
- A qué público adulto se dirige.
- Qué datos recoge o no recoge.
- Si mantiene instrucciones claras.
- Si funciona en móvil y escritorio cuando sea digital.
- Si conserva el carácter complementario y no oficial del proyecto.

## Uso de IA

Se permite usar IA como apoyo para redactar, revisar, adaptar o programar, pero el resultado debe ser revisado por una persona antes de publicarse.

No deben introducirse datos personales sensibles en herramientas externas.

## Aviso institucional

Los recursos de El Formador Junior son materiales personales, complementarios y reutilizables. No son recursos oficiales de ninguna entidad formativa salvo autorización expresa.
