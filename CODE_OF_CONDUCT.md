# Código de conducta · El Formador Junior

El Formador Junior es un proyecto personal de recursos pedagógicos digitales reutilizables para formación de adultos.

Este espacio debe mantener una comunicación respetuosa, clara y útil.

## Conductas esperadas

Se espera que las personas que participen en issues, pull requests o comentarios:

- Usen un tono respetuoso.
- Critiquen ideas, recursos o errores sin atacar a personas.
- Propongan mejoras de forma concreta.
- Respeten la orientación del proyecto hacia personas adultas.
- Eviten lenguaje ofensivo, discriminatorio o despectivo.
- No publiquen datos personales propios ni de terceros.
- No compartan información sensible, credenciales, claves o códigos privados.

## Conductas no aceptadas

No se aceptan:

- Insultos, acoso o ataques personales.
- Comentarios discriminatorios.
- Publicación de datos personales sin consentimiento.
- Spam o autopromoción no relacionada.
- Uso de issues para debates ajenos al recurso.
- Presión para obtener soporte urgente o personalizado.

## Enfoque del proyecto

Los recursos de El Formador Junior son materiales personales, complementarios y reutilizables. Su finalidad es educativa y pueden requerir adaptación según el contexto, el grupo y el criterio de la persona docente.

## Aplicación

El responsable del proyecto podrá cerrar issues, eliminar comentarios o restringir la participación si una interacción se aleja de estos criterios.
